# GitHub安全墙功能本机应用

2026-10-16，基于GitHub main提交106f4fd。

主窗口顶部新增“安全墙”，测头任务内入口复用同一工作页。可编辑底座B坐标下的墙方向、垂直距离和预留范围，保存草稿，检查静止反馈快照或完整关节预览路径，查看碰撞部位和测试记录。远端同时新增的“坐标到点”页面随同应用，默认保持执行锁定。

本机应用修复：

- 新页面使用统一减号/加号数值控件，支持0.1步进；固定方向角按所选坐标轴自动填写。
- 安全墙页隐藏时暂停界面刷新。
- 修复Qt合成透明墙时因帧缓冲alpha混合产生的蓝色异常，保持橙色透明墙与正常场景颜色。
- 网格测试改为核对资源真实数量与底座/J1–J6完整性，不假定每台机器的厂商网格都含32部分。本机资源为19部分。
- 明确330 mm仅为未核实初值，不将远端文档中另一台电脑的300 mm设置当成本机实测值。

验证：184项离线测试通过，本机实际OpenGL工作页9项检查通过。使用隔离配置和假反馈验证墙面显示、草稿保存、实际本地网格碰撞判断、碰撞标红、快照/实时显示区分、隐藏刷新以及退出清理。没有连接实机、发送运动或修改实际安全墙参数。

## 使用

关闭并重新打开软件，进入顶部“安全墙”。先核对底座坐标轴的朝向、底座中心到墙的垂直距离及预留距离，再更新三维草稿或保存。测试工具/测针前还需核对完整工具的包络半径，不能将50 mm初值直接当成实测结果。

本机未找到已有safety_wall.json，因此保留默认未确认、未显示草稿，安装不创建或替换墙配置。若后续有原配置，打开页面会读取原值；仅点击保存才写入。

安全墙目前是显示模型的虚拟采样碰撞检查，尚未接入连续实机运动拦截。显示宽高不限制碰撞检查范围，禁入侧按无限半空间计算；路径检查不是连续碰撞证明。靠近墙自动停的硬件/控制器保护未实现，不能据此做实际碰撞试验。现有DI_1触发停止、反馈中断、异常和人工停止仍按实机控制模块处理，软件停止存在通信与制动延迟。

本地厂商显示资源仅留在本机，不随Git上传；源代码和日常运行目录使用同一份本机资源。本次对GitHub新功能的兼容修复保存在本地项目中。
