# 全局安全墙

现在只有一份应用中的安全墙配置，路径仍为 `data/probe_workspace/safety_wall.json`。所有三维视图和本软件的实机控制共同使用它。

## 界面与操作

主界面各页顶部常驻全局安全墙状态和设置入口。设置页主要保留墙的方向、底座中心到墙面的垂直距离、墙内侧禁入预留，以及覆盖整个测头工具的包络半径。绘图尺寸、额外停止预留和诊断检查折叠在“更多参数与检查”。

“查看未应用草稿”只改变设置页本身的预览；“应用到全局”保存并广播给所有现有视图，之后新开的视图也会加载同一份配置。旧的坐标目标预览随应用配置变化失效。双机械臂视图按测量臂B的显示底座位置绘制同一堵墙，绘图宽高不意味着可以从边缘绕过：软件检查仍按整个禁入半空间进行。

现场方向、距离和工具包络需要实际核对。当前用户不知道墙的方位和距离，因此不自动写入任何“已确认”的墙面数据。330 mm和50 mm只是编辑参考值，不能当作现场测量值。未确认时，本软件的实机运动保持锁定，虚拟预览仍可使用。

## 软件运动检查

`ManualControl` 默认接入全局墙面守卫；点动、定距及指定坐标共用同一检查入口。协议隔离单元测试显式使用 `wall_guard=None`，生产界面没有关闭守卫的开关。

- 发运动指令前，后台核验显示模型的连杆及已确认工具包络，路径无完整连续逆解、进入墙面或额外停止预留区时不发送指令。原生连续点动没有固定终点，只检查起步方向的预留区段；之后持续依靠反馈检查，不能声称已验证整段未来点动路径。
- 每个反馈周期检查当前模型姿态，并在有关节速度时按短时恒速外推检查0.1、0.2、0.3秒的姿态。进入停止预留区或检查失败，投递最高优先级停止请求。UI全局状态同步显示预警。
- 墙面配置变化时取消原授权和目标，不自动继续运动。错误配置文件、缺少模型、工具包络未确认等情况保持拒绝运动。
- 逆解与路径检查在控制器锁外运行，人工停止、DI触发和松手可以取消后台计算；停止后不会继续发送原移动。

## 实际边界

这是本软件的路径与反馈检查，**没有写入控制器安全平面，也不能保护由其他软件或示教器发起的运动**。保存数据中的 `geometry_verified` 和 `motion_enforced` 仍为False，不用文件标志假称硬件保护已部署。

碰撞模型未完成实物校准，路径检查为离散采样，短时速度预测也不能证明加减速或制动距离。额外停止预留不是经过实测认证的停止距离。系统不能据此保证实机绝不碰墙，不能替代控制器安全功能和实体急停。真实防护部署还需要确认墙的几何位置、整个工具外形及实际停止距离，并核对控制器提供的安全配置。

## 验证

215项离线回归通过，覆盖默认全局守卫、未知配置锁定、已应用/未应用草稿隔离、已有和后建视图广播、三种运动入口检查、墙面禁止时无运动指令、停止打断路径检查、配置变化取消原目标、反馈越界停止及损坏配置拒绝使用。

Windows真实OpenGL验证设置页、实机控制、测头工作区及双臂三维视图共享同一配置，检查参数和日志全部位于隔离fixture目录。另用19个显示模型部件离线核验安全路径接受和靠墙姿态拒绝；当前姿态检查中位耗时约0.27 ms，约58.84 mm路径完整检查约108 ms。没有连接控制通道或移动真实机械臂。上述数字只是这台电脑的离线测量，不是实机停止性能。

安装仅覆盖源码和运行模块，保留原始墙面文件、采点、标定及控制器配置。
