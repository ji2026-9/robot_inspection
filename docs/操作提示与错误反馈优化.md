# 操作提示与错误反馈优化

范围：实机控制、路径预览、测头任务、白球采集与分析、安全墙、停止测试、设备连接和工作页加载失败。

- 统一提示条：红色为失败，黄色为注意，绿色为完成，蓝色为操作说明。使用明确文字和下一步，不依赖颜色判断。
- 实机控制错误显示于页面顶部，异步路径预览失败同步到顶部。成功预览失效后及时撤掉旧成功提示，错误不被周期刷新覆盖。
- 多目标报错指出第几个执行目标和坐标；重合或小于0.01mm时说明无需重复移动，超过2000mm时显示实际距离。
- 提示可选中复制，支持右键“复制完整提示”。原始原因保留，文字按纯文本显示。
- 无法确认停止等实机关键异常使用异步弹窗，重复异常不重复弹窗；关闭提示不恢复控制。输入校验使用持久提示条，不用弹窗打断编辑。
- 实机控制页面不使用外层整页滚动，参数区独立滚动，提示出现后仍保留底部停止按钮。
- 保存原点和生成预览完成都有醒目反馈。没有改动运动授权、采点、停止命令或真实硬件配置。

验证：235项离线回归通过（2项跳过）。Windows OpenGL 隔离界面验收通过，验证目标错误、处理建议、测头任务、安全墙和停止按钮完整可见。没有连接实机控制通道，没有移动机械臂。
