# 白球采集与重复性分析

入口：主界面「位置记录与手动任务」→「测头采点」→「白球采集与重复性分析」。程序只读取反馈，不使能、不移动机械臂、不写输出或 TCP 参数。

现阶段不要求提供测针型号或白球直径。未知测针有效半径时，球面拟合只得到组合半径及当前配置 TCP 坐标下的拟合中心，不能分离出白球真实直径，也不能由此认定测头 TCP 已标定。固定朝向下，未知恒定 TCP 偏移可能整体平移点云。

有两种独立采集组：
- 球面分布采点：至少 9 个分布接触位置，覆盖不同周向和高度，保持同一朝向。原地手拨测针、共面点、只扫很小一片球面不适合拟合，会拒绝或警告。
- 同一点重复采点：至少 5 次真实接触同一位置，同一接近方向及朝向，每次退开再接触。只统计本次离散程度，不能据此认定绝对测量精度。

白球必须先固定，采点期间不移动。未确认实际接触条件、输入仍为高、无有效反馈或采点保存异常时不能开始。新组只收开始之后的事件，不会加入此前三次手动轻触。每组最多 500 点；工具 / 用户配置变化、朝向变化超过 0.2°、断线或关闭窗口会停止本组，避免继续混入不一致数据。0.2° 是实验分组阈值，不是精度保证。

原始触发记录继续独立保存。采集组写入 data/probe_workspace/contact_sessions/，每次新增点原子保存。可显式排除 / 恢复选中点，原始记录不删除，报告列出排除编号。打开历史组默认已停止，重新分析，不自动恢复采集。导出包括样本、排除标记、结果和未验证标志。

球面拟合报告组合尺寸、拟合中心、径向残差和几何条件；重复性报告各轴标准差、三维离散 RMS 和最大两点距离。残差小或多次结果一致，都不证明尺寸准确。所有结果保持 calibration_verified=false、accuracy_verified=false、tcp_calibrated=false、controller_latched=false、hardware_executable=false。

采样仍来自 DI_1 变化后收到的反馈帧，并非硬件触发锁存；测头错误输出未独立验证。开始实际接触实验前，需由操作者确认固定与接触条件，后续运动配合另行说明。

验证：54 项自动测试通过（包括球面已知几何、重复性统计、原地 / 共面 / 小范围退化、配置与朝向混合、异常点、排除恢复、保存失败重试）；15 项安装版隔离反馈 GUI 检查通过。示例拟合截图与合成样本只用于测试，未混入真实位置库或触发记录。尚未采集真实白球接触数据。
