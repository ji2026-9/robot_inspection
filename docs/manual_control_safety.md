# 连续点动的保护规则

操作说明见 [manual_control.md](manual_control.md)。默认连续点动：按住方向启动、松手请求停止；收到停止应答并核对后续反馈稳定后，自动恢复输入权限。恢复输入本身不发送运动，必须再次按下方向才启动。

普通松手不需要重新确认。红色停止按钮或窗口失焦仍需手动继续；测头触发、报警、断线、配置变化、超时或行程越界会保护锁定，不能自动恢复。保护事件发生在停止核对期间也会撤销自动恢复资格。

本次确认有效10分钟；单次连续按住的行程上限可设0.01–100 mm（默认100 mm），时间上限30秒，仅支持基座用户坐标0的XYZ平移并保持姿态。正常反馈模式允许点动状态8；非预期运行模式、偏离选定方向或姿态变化会停止。定距模式单次0.01–100 mm，目标速度1–20 mm/s整数；本次确认期间可重复调整。

按住信号须持续刷新，超过200 ms未刷新会请求停止；反馈异常或中断也会请求停止。一个按住操作只发一次原生MoveJog，移动中和停止核对期间不缓存其他方向。设置速度倍率的应答返回后再次检查松手/取消，已取消时不发点动启动。

连续点动倍率是控制器全局速度百分比，默认1%，可选或输入1–10的整数百分比；不是绝对mm/s。倍率在开始点动时设置，停止后不会自动恢复更高倍率；负载、重心和标定参数不修改。

所有这些都是电脑端软件保护。反馈位移上限、稳定判据和速度倍率不构成无过冲保证，也没有安全认证；实际运动停止距离未验证。实体急停必须可用，厂家安全接口说明见 [CR A 系列官方手册](https://download.dobot.cc/2024/05/Dobot%20CR%20A%20Series%20User%20Guide%20V1.8_20240511_en.pdf)。

达到用户设定的点动行程上限按正常停止处理，核对停止后自动恢复输入；超时或硬保护越界仍会锁定。切换离开控制页、主窗口失去焦点均请求停止，需要手动继续。参数越界、非数字或无效整数由界面和后端共同拒绝。扩大参数范围不改变默认低速，也不修改控制器工具/负载/标定配置。

## 停止优先修复（2026-10-16）

执行按钮下方增加红色“停止运动（Esc）”，按下即请求停止，不必等鼠标松开；底部停止按钮保留。在控制页按 Esc 同样请求停止。

停止事件在等待线程锁之前置位，唤醒控制线程，撤销运动授权和待发目标。控制线程先处理停止再取移动任务，不重放被取消的目标。测头 DI_1=1 在每帧反馈处理中锁存停止，松开测头不会自动恢复本轮。

修复定距移动停止失败：旧版本先发送 MoveJog()，控制器返回 -1 后异常中断，未继续发送 Stop()。新版本定距模式直接发送 Stop()；原生点动分别尝试停止运动队列和取消点动，任一失败不跳过另一请求。失败仍锁定并明确提示无法确认停止，不以应答代替真实停止反馈。

日志增加停止请求原因、DI位值、请求时间和失败指令清单。已有旧日志没有触发时刻记录，不能据此判定那一次是否收到 DI 信号。

138项离线自动测试和9项工作台检查通过，新增覆盖真实协议解析中的拒绝应答、短DI脉冲、待发移动取消、停止按钮按下及Esc。没有发送实机运动指令。最高优先级是本程序的处理顺序，不是硬件急停：正在进行的通信应答、反馈采样、网络与制动仍有延迟；未验证实机停止距离。升级后先在静止状态核对DI触发及停止应答，不能直接拿碰撞测试验证。
