# 虚拟机械臂跟随路径

已安装到 E:\robot_project\inspection_app，并同步本地仓库 software。没有提交或上传 GitHub。

进入「位置记录与手动任务 → 模拟视觉」，载入四孔示例，读取实机当前位姿作为起点，生成路径。程序在后台逐帧计算显示模型的完整位姿逆解，完成后点击「播放虚拟机械臂」。手动任务也自动计算。无需使能实物机械臂。

- 使用厂家显示模型的法兰轴定义及记录中的工具六维偏移，同时约束位置和朝向。
- 接续上一帧的关节解；目标残差超过 0.5 mm / 0.25°，或相邻帧关节变化超过 12° 时，停止在最后有效样本，标出失败目标。失败不等于已证明物理不可达。
- ±360° 是软件求解范围，不是从控制器读取的物理关节限位。接近模型奇异位置会提示。未验证碰撞、动力学、真实运动速度和加速度、测头 TCP 或实际可达性。
- 三维模型的黄色连线只表达已配置的法兰到 TCP 偏移，不是实际测头形状。
- 「聚焦路径」包含整条轨迹上的机械臂姿态，避免抬臂后模型出画。
- 导出文件包括各帧关节角和求解报告，所有硬件执行、物理标定及碰撞验证标志仍为 false。导入文件会重新求解，不信任其中预存的关节轨迹。
- 修改参数、工具配置、关闭窗口会使旧计算取消；过时结果不能覆盖新任务。

验证：41 项自动测试通过；19 项安装版 GUI 检查通过，包括完整四孔求解、界面响应、播放暂停复位、导入重算、不可达停止、取消和小窗口。静态样本来源于实机位置库，GUI 检查使用隔离反馈，不发送设备指令。本次 289 帧全数得到显示模型连续逆解；这不是对真实机械臂精度或安全性的认证。
