# 测头触发停止（实验功能）

入口：位置记录与手动任务 → 测头采点 → 测头触发停止 · 设置与隔离演练。

新增“静止触发通信测试”：无需勾选运动监控的负载等现场声明。操作者确认机械臂静止、无运动程序、不点动、不移动白球后，才能开始。仍需有效新鲜的静止反馈、DI_1=0、无报警及日志可写。等待手动轻触测针，在静止状态发送两条停止请求并核对应答与静止反馈；如果测试期间检测到运动也请求停止。30 秒后结束，不自动重试。它只验证输入和停止请求的通信链路，不验证运动中制动、点动兼容性、过冲或停止距离，绝不能替代运动测试。负载未确认时只能进行此静止通信检查，不能据此继续向白球运动。

静止通信测试误拦截修复：现场待机时瞬时速度估计不为零，而位姿范围很小。该模式改为要求连续 0.4–0.5 秒、帧间隔不超过 100 ms、工具 / 用户配置和时间顺序一致的待机无报警反馈；窗口内各 TCP 平移轴范围小于 0.02 mm，各姿态 / 关节角范围小于 0.01°。漂移、断线、运动状态、配置变化或控制器时钟回退使窗口失效。仅静止通信测试使用此判定，运动监控仍使用原速度条件。静止通信测试成功标记 communication_verified=true、confirmed_stopped=false，避免误认为已验证运动制动。现场只读反馈检查可形成稳定窗口；没有发送控制命令。此次修复后共 70 项自动测试、13 项隔离界面检查通过。

默认关闭，不保存启用状态，重连不自动启用。隔离演练使用合成 DI 数据，不建立控制连接，不混入真实触发记录。实机开关必须逐项人工确认现场负载、重心、空间、急停和无接触测试条件；本次开发没有勾选这些确认，也没有在实机上发送停止、运动、使能或控制接管指令。

启用后每个反馈包检查 DI_1。DI_1 高电平、无效输入、反馈间隔异常、超过 200 ms 无新反馈、控制器报警、配置改变、断开连接、关闭窗口、人工结束或 30 秒到期，均触发一次停止请求。本次结束后必须重新人工启用；不会自动退回、恢复运动或清除报警。

停止通道为独立 TCP 29999 连接，只有固定白名单 MoveJog() 与 Stop()。MoveJog() 不带轴参数，请求停止点动；Stop() 请求停止运动队列 / 工程。每条指令有连接和响应超时，响应大小有界，不自动重试，不申请 RequestControl，不修改控制模式，不执行 EnableRobot、负载、DO 或运动设置。不保证当前控制模式会接受这些指令，特别是 DobotStudio 官方点动的兼容性尚未实测。

状态区分 off、armed、pending、acknowledged、confirmed、failed、simulated。控制器成功应答不会直接标成“已停住”；应答后需要同一反馈连接、同一工具 / 用户配置的三个新鲜连续反馈帧，关节 / TCP 六轴速度绝对值均小于 0.01（厂家反馈字段单位），且模式为静止 / 下使能 / 暂停、running=false，才显示反馈静止。响应失败、处理超时、两秒内无法确认静止时明确失败。该阈值用于实验状态判断，不是停止距离或测量精度保证，也不是安全等级认证。

实机日志在 data/probe_workspace/stop_monitor_logs/。启用前先确认日志可写；停止派发不会等待触发时磁盘写入，结果再原子保存。日志故障会显示，不能因保存故障阻止停止请求。原始接触日志继续独立保存。

限制：网络 / 电脑调度 / 反馈周期 / 制动都有延迟；DI 短脉冲可能漏检。电脑进程被强制结束或断电时软件无法保证发出停止请求。反馈静止不代表测针没有过冲，也不证明标定有效。本功能不是硬件探测锁存、硬件联锁或急停，不得替代人员保护。需要在正确负载配置、远离白球和障碍物的条件下，由现场操作者验证兼容性与停止行为，再评估是否满足接触实验需要。
