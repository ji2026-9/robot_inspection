# 离线三维定位与路径预览

入口：检测软件顶部「三维定位与路径预览」。未加载检测结果时显示可选孔的示例任务；检测并选择可靠孔后，重新打开窗口，绑定当前照片和所选孔。可在三维窗口里调整本次预览孔清单。

外观采用 OpenGL 光照、深度遮挡、网格地面和投影阴影。工件按现有训练照片中的四缸孔箱体做近似，保留开放孔、内壁、周边螺孔与铸造筋。尺寸是假设值，不从照片宣称测得。

默认孔径100mm、孔间距115mm、端面高度250mm、箱体高度140mm、接近距离65mm、进入深度35mm、测球直径6mm。尺寸在界面内可调整。机械臂基座名义位置：A=(-480,100,0)、B=(480,100,0)，单位mm；不是实机安装尺寸。

左右拖动旋转；右键拖动平移；滚轮缩放；俯视/恢复斜视切换；开始、暂停、时间滑条可检查路径。测头路径为安全高度转移、接近、孔口、进入、退出、抬升。不同孔之间先抬升。当前只演示进退孔，不伪造接触测量数据。

## 坐标与验证边界

当前照片的H01-H04与名义CAD槽位对应，保留源像素坐标。四孔不完整时不自动猜测缺失孔的槽位。此对应不是像素三维重建，也不是永久物理身份。四个近共线孔心无法单独给出平面单应矩阵或完整工件姿态。

任务JSON包括模拟世界/A基座/B基座/虚拟相机变换、所选孔、进退路径及显示关节轨迹；`simulation_only=true`，`hardware_executable=false`，`calibration_verified=false`，`collision_verified=false`。测量就绪检查和真实设备接口保持不变。

显示机器人采用本机已安装DobotStudio的CR5系列显示网格和该显示文件的关节层级。它没有被认证为实际CR5A的尺寸、关节限位或运动学模型。IK仅匹配显示模型末端位置和向下方向，没有碰撞检测和控制器执行验证。显示模型残差不是实机精度。

## 环境与本地网格

额外运行依赖：`pip install -r requirements-simulation.txt`，其余沿用项目numpy/scipy/PySide6。
可选网格缓存：`inspection_gui/assets/local_dobot_cr5.npz`。本机从已安装的DobotStudio资源转换，仅本地使用，不提交至GitHub、不打入对外分发包；另一台电脑没有缓存时显示程序化备用模型。也可用环境变量`INSPECTION_ROBOT_MESH`指定合法来源的本地缓存。

## 验证

`tests/test_offline_planning.py`覆盖坐标链组合/逆变换、已知参考点、选孔过滤、缺孔处理、参数约束、进退位置和显示末端轨迹残差/关节跳变。程序界面另做原有检测流程回归和实际OpenGL窗口显示检查。模拟结果须与真实标定和设备测试分开记录。
