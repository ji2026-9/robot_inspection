# 页面流畅度与模型管理更新

2026-10-16。重开软件生效，不需要额外安装依赖。

## 界面变化

- 模型管理增加孔检测模型、零件定位模型、文件可用状态、大小、路径和当前配置版本。页面只读取文件信息，不加载推理模型、不启动训练。
- 添加数据/训练、查看验证结果、打开模型文件夹、刷新信息集中显示；训练与验证工具仍在独立窗口运行，任务状态和最近150行日志在管理页显示。管理工具运行时禁用重复启动按钮。
- 不再把读取到本地配置直接显示成“已通过验证”，避免把文件存在误认为精度合格。

## 卡顿修复

- 标签容器保持不变，减少移除/重插标签导致的布局与绘图资源重建；首次点击先显示页面准备状态，快速切走时不创建已放弃的页面。
- 在主窗口显示之前准备OpenGL合成，启用共享上下文，避免首次添加三维页时重建已显示的原生窗口。启动时会提前花费一次绘图初始化时间。
- 三维显示资源共用一份后台加载结果，减少重复解压和求解初始姿态；数组只读，GPU资源仍由各视图管理。
- 隐藏三维页停止播放和界面刷新；隐藏测头页不刷新三维显示，但保留后台触发记录。实机停止检测仍处理每一帧反馈，不降低采样频率。
- 路径显示残差在计算线程完成；三维预览只复制需要的几何字段，避免复制完整照片/掩膜。
- 离开视觉页后停止执行照片缩放和相机画面绘制，返回时按当前数据重绘；相机采集线程保持原有生命周期。
- 实验记录后台读取，表格每批最多80行/约8ms分批填充；未改变的记录不重复读盘。固定可拖动列宽替代每次插入后重新遍历整表计算宽度。测头位置表也取消重复自动计算列宽。

## 验证结果与范围

- 147项离线自动测试通过，包括停止优先级、测头DI短脉冲停止链路，以及页面复用、共享资源、隐藏刷新、大批记录、模型文件信息等回归测试。
- 9项工作台流程检查通过。
- 本机Windows实际OpenGL、相同显示资源、模拟反馈对比：三维首次进入约1.10秒，优化后约0.34秒；两幅三维视图的上下文初始化次数从4次降为2次。优化后重复切页约7–21ms（不含显示器呈现延迟）。数值会随机器状态和数据量变化。
- 实际四孔337帧路径计算约3.53秒，在后台完成；10ms Qt定时器观测到的95分位间隔24.51ms，最大112.48ms。计算不是瞬间完成，仍会显示生成状态。
- 所有验证禁止真实网络连接，没有操作实际机械臂或训练模型。不保证任何数据规模、硬件、相机流或驱动环境下都不存在卡顿；本轮修复覆盖已定位和复现的问题。
