# 统一工作台与自定义控制参数

2026-10-16 更新。重开日常软件即可使用，无需安装额外依赖。

## 直接进入功能

主窗口顶部提供视觉检测、三维预览、实机控制、测头任务、白球分析、停止测试、设备连接、实验记录、模型管理。点击工作页直接操作，不再逐层打开功能窗口。首次进入时加载，切换保留当前状态；小窗口可滚动。视觉检测侧栏的重复入口已收起。

记录页载入数据自动返回视觉检测。测头任务与三维页中原有的功能入口也会转到对应工作页，不会另开一套窗口。离开实机控制页时请求停止；回来后需要手动继续，不自动恢复运动。

## 参数如何用

- 定距：距离0.01–100 mm，可直接输入小数；目标速度1–20 mm/s整数。修改参数后重新选择方向，核对目标后按住执行。
- 连续点动：按住方向持续点动，松开请求停止。行程上限0.01–100 mm，倍率1%–10%整数，默认1%；实际速度还受控制器点动设置影响。
- 两种模式分别记住本次窗口内设置的参数。距离和速度框既可选预设，也可直接输入。
- 正常松手后核对停止反馈，随后可反复点动；红色停止或切页需手动继续。测头触发、断线、报警等异常需处理原因后重新确认。
