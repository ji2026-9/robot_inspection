# 界面精简

四个主入口：工作台、实机控制、测量任务、记录与结果；设置集中设备、白球验证、安全墙、停止诊断、模型和版本。
实机控制使用单个坐标、多点路径、返回保存位置三个明确目标类型，只展开相关参数；共用预览与执行按钮。返回位置文件格式保留。
触碰采点默认进入只读采点，位置库和离线诊断折叠保留。功能页继续延迟加载并复用，不创建新控制连接。
安全墙全局入口、停止联锁、配置及保存数据不变。自动圆孔探测/退离仍未开放。
验证：22 项针对性测试通过，Windows OpenGL 离线验收通过，包括跨页面 Esc 停止、原点来源、列表顺序及关窗清理。未连接或移动实机。
