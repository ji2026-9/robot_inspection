## 一、核心结论（先说结果）

> **差距来自模型，不是管线。**
>
> 用**他完整的管线**（part 约束 + 旋转复查 + 多尺度补检 + 稳健拟合 + 边缘精修），
> 只换 bore 模型：我方 `best.pt` 在测试3 仍然只有 3/4；他的 `bore_best.pt` 是 4/4。
> 而 `best.pt` 与 `bore_best.pt` 的差别只有一处 —— **训练数据量：20 张 vs 28 张**。

## 二、三模式实测（同一套代码、同一套后处理，只换模型）

| bore 模型 | 输入 | 测试1 | 测试2 | 测试3 | 测试4 | 单张耗时 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| **我方 `best.pt`**（`friend` 模式） | 640 / retina | 4/4 | 4/4 | **3/4** | 4/4 | 0–2 s |

| 模型 | 该孔置信度 | 结果 |

→ 说明不是我方管线缺功能，而是**我方模型确实"看不见"这个反光孔**。

## 三、数据泄漏排查（结论的前提）

在他模型更强之前，必须先排除"他的模型训练过我们的测试图"这种可能。

**方法**：64×64 灰度标准化指纹相关。**方法灵敏度自检**（先证明它抓得住重复）：

| 对比 | 得分 |
| --- | ---: |
| 测试1 vs 测试1（同一张） | **1.0000** |
| 我方 `005.jpg` vs 他的 `d32d76981de4…` | **1.0000** |
| 测试1 vs 他的 `711a70e3b880…`（不同照片） | 0.2901 |

**结果**：

| 检查 | 结果 |
| --- | --- |
| 我方 4 张测试图 是否在我方 25 张数据集里 | **不在**（最高相关 0.33） |
| 我方 4 张测试图 是否在他的 28 张里 | **不在**（最高相关 0.33） |
| 我方 25 张数据集 与他的 28 张的重叠 | **25/25 完全一致**（得分 1.0000，两边是同一批原始照片） |
| 他多出来的 3 张 | 尺寸 4096×3072 / 3072×4096（与我方 2592×4608 不同的拍摄），标注 `bore, part` |

→ **没有数据泄漏**。测试1~4 是两边都没训过的干净图，结论成立。

## 五、交叉验证：用他的模型当"独立证人"检验我们的新拟合

把「我方 A/B/C 三种拟合给出的圆心」和「他的模型给出的圆心」按最近邻配对：

| 方法 | 中位差 | 平均差 | **最差** |
| --- | ---: | ---: | ---: |
| A `cv2.fitEllipse`（原做法） | 3.23 px | 5.63 px | **34.79 px** |
| B 稳健 RANSAC | 2.37 px | 4.62 px | 32.76 px |
| **C 稳健 + 边缘精修（已采纳）** | **1.97 px** | **2.34 px** | **7.05 px** |

最差情况从 **34.8 px 降到 7.05 px**。测试3 那个反光孔：

```
我方 C 拟合      = (1459.97, 2572.46)
他的模型中心     = (1463.74, 2578.42)   →  相差 7.05 px（图上 4608 像素高，约 0.15%）
```

两个**独立训练**的模型 + 两套**独立实现**的拟合，落在同一个位置 ——
这是对"第 1 档采纳 C"最有力的旁证：C 找到的就是真实孔口内壁，而不是漂移。
