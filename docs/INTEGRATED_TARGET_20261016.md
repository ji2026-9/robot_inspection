# 实机控制内的指定坐标与预览

已把指定坐标合并进实机控制页的移动方式下拉框，取消独立“坐标到点”顶层入口。原有连续点动与定距移动保留。

操作：选择“指定坐标”→读取当前位置或填写基座用户0下的 XYZ→设置1–10 mm/s目标速度→生成路径预览→播放或拖动进度条观察关节与路径→在本轮控制已启用时点击“确认预览并执行”。保持当前工具姿态，采用 MovL 直线移动；全局倍率仍影响实际速度。预览无需启用控制，播放与拖动不发送任何机器人命令。

坐标、速度、连接、工具配置、起点位姿改变后，旧预览作废。开始执行即消耗预览，不重复发送；停止、隐藏控制页、断开或结束本轮均取消旧预览。坐标模式点击执行后无需长按，连续点动和定距移动仍保留原有松手停止行为。

底部停止按钮与 Esc 始终可用，先投递最高优先级停止请求，再更新预览界面。现有 DI_1触发、反馈超时、失焦及异常停止逻辑保留；软件停止仍依赖通信和控制器响应，不等于实体急停。

右侧预览基于项目的显示模型和关节逆解，并不认证控制器实际插补或设备精度。有已确认的安全墙时检查显示模型连杆路径；未配置时明确提示。工具完整包络和现场障碍未核验，虚拟墙并非硬件安全功能。预览不完整或已检查的墙间隙不足时不允许提交本次目标。

验证：188项隔离离线测试通过，新增完整关节预览、参数与起点失效、取消后台任务、明确执行一次及松手保持坐标指令等回归；Windows真实OpenGL渲染、播放、1000×720窗口适配通过。所有测试禁止硬件联网，没有连接或移动真实机械臂。

部署同时更新源码和日常运行目录；不修改用户标定数据、控制器配置或真实安全墙参数。重新打开软件后生效。
