# 模拟视觉流程

已安装到 `E:\robot_project\inspection_app`，本地仓库副本和测试同步更新。

主界面点击 **位置记录与手动任务**，进入 **模拟视觉**：

1. 点击 **载入四孔示例**，无需填写坐标。
2. 点击 **生成模拟视觉路径**，查看四个孔转换后的 B 基座坐标。
3. 点击底部 **播放 TCP 轨迹**。每个孔依次显示接近、测量候选点、退回；支持拖动进度。
4. **聚焦路径**可放大查看路径；**恢复斜视**恢复整体视角。

默认起点是明确标注的示例位置，不来自实机，因此机械臂不在线也能运行。没有真实关节起点时只显示 TCP 路径，避免制造机械臂已完成逆解的假象。连接有效时，可选择 **使用实机当前位姿作为起点**，生成时重新读取新鲜反馈；三维骨架保持采样关节姿态，仍不代表实际关节运动。

## 模拟坐标约定

输入文件必须明确标记 `source=simulated_vision`，包含来源坐标系、mm/deg 单位、唯一孔号、三维位置和单位长度的接近方向。接近方向指向孔，并被作为工具 +Z 的示例方向；绕该轴的滚转角采用示例约定。

转换文件须明确标记 `kind=simulation`、`calibration_verified=false`，从 `camera` 或 `robot_a_base` 转到 `robot_b_base`。矩阵旋转部分必须正交、无镜像或缩放。当前没有真实标定，不使用隐含的单位矩阵冒充标定结果。

示例相机四孔坐标经过 15° 的 Z 轴旋转和 `[-300,-100,600] mm` 平移后成为 B 基座候选点。它们是测试数据，不是实际工件位置。孔中心暂作为 TCP 候选目标，没有真实测球接触补偿。孔间路径没有验证逆解、可达性或碰撞。

缺少坐标/转换、单位错误、重复孔号、零或非单位接近方向、无效矩阵及过远目标会阻止生成。1500 mm 仅为预览数值范围限制，不是机械臂可达性判定。

所有导出的任务固定为仅预览，硬件执行、标定、逆解和碰撞验证标志均为 false，没有新增运动接口。

## 断线与配置变化

反馈失效时禁用当前位置记录、实机起点读取及姿态核对，清除旧实时模型和失效的核对结果。使用实机起点的模拟任务必须在生成时取得有效反馈。重连不会把断线前的旧数据当作新数据。

用户 / 工具编号或偏移变化时，依赖旧实机起点的预览失效，需要重新读取起点。示例数据的离线预览可以继续使用，界面始终标记模拟任务。
