# 取消用户此前的10 cm行程与低速上限

本次只取消软件额外增加的限制，不写入或提高控制器的真实安全限制，不自动选择更高速度。

- 连续点动不再默认带100 mm行程上限，界面隐藏该上限输入。后台默认明确记录为None，反馈经过100 mm时不再因旧上限停止。显式调用API传入自定义距离时仍按该距离停止。
- 连续点动倍率从软件1–10%放开到控制器协议1–100%；默认仍为1%。用户明确按住方向时才会提交该倍率和运动命令。
- 定距移动由0.01–100 mm放开到现有单目标支持的0.01–2000 mm。
- 定距移动及指定坐标取消软件20/10 mm/s上限，允许正整数目标速度，实际可接受的最大速度由控制器检查。拒绝的命令不重试、不自动改变控制器设置。
- 预览时间使用用户填写的目标速度及实际读取的全局倍率估算。未核验控制器是否接受的速度，不能视为已确认实机速度。

仍保留：松手停止、人工停止最高优先级、DI_1触发停止、连接/配置变化检测、反馈超时停止、失焦停止、模式/姿态/方向监控、单次连续点动30秒超时及本轮控制10分钟授权。

协议依据：[Dobot官方V4 API](https://github.com/Dobot-Arm/TCP-IP-Python-V4/blob/main/dobot_api.py)：SpeedFactor取值1–100；MovL的speed为整数mm/s，其上限为控制器允许的最大运动速度。

验证使用模拟通道与隔离反馈：模拟150 mm点动不会被旧100 mm限制停止，之后DI触发仍停止；较高速度按输入传递、无静默裁剪；界面及数值增减按钮可输入新范围；不连接、不移动真实机械臂。
