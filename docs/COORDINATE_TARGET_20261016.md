# 坐标到点 · 预演与实际执行（2026-10-16）

入口：主界面“辅助工具 → 坐标到点”，或“实机控制 → 输入目标坐标 · 带安全墙预演”。

## 最短操作流程

1. 打开窗口：三维视图里已经显示机械臂当前位姿，控制通道会在后台自动连接（只检查 TCP 模式，不使能、不运动）。
2. 点“读取当前位置作为目标初值”，改 X / Y / Z 到目标点。姿态默认保持当前工具姿态，不用管 Rx/Ry/Rz。
3. 点“生成路径预演”：后台解算整段逆解并播放路径。
4. 勾选“本次工具与现场已核对”，点“实机执行”。第一次执行时会自动启用本轮授权（10 分钟），随后发送一条慢速目标移动。

安全墙是可选的。没有确认墙方向时，只解算路径、不做碰墙检查；确认了墙方向后，才会用显示模型逐帧检查整条路径并显示间隙。

## 提前报错的条件

任一条不满足即拒绝执行，且不发送任何运动指令：

- 逆解不完整（目标不可达，或相邻采样关节跳变超过 12°）；
- 已设置安全墙时：采样路径进入禁区，或采样最小间隙低于执行门槛 15 mm；
- 已设置安全墙时：工具包络半径未填写 / ≤0，或未勾选覆盖确认；
- 反馈不新鲜（>200 ms）、机械臂未静止、有报警、测针已触发，或坐标 / 工具配置、连接代次发生变化。

## 执行时的保护

- 目标移动速度 1–10 mm/s（默认 5 mm/s），单次一条 MovL，不排队。
- 执行前会自动启用本轮授权；勾选“本次工具与现场已核对”（含负载与重心、工具坐标、实体急停可用、人员已离开运动范围）是必要的人工确认。
- 运动中持续监测：偏离目标直线走廊（横向 >0.2 mm 或姿态 >0.5°）、测针 DI_1 触发、反馈中断、超时或人工停止都会请求停止并锁定。
- 执行前重新核对起点、工具偏移、安全墙指纹与连接代次，任一项变化都要求重新预演。
- 关闭窗口会撤销由本窗口启用的授权，不会留下未锁定的会话。

## 边界

- 没有安全墙时，软件只保证路径可达，不保证运动范围内没有障碍。
- 有安全墙时，碰撞检查是**采样**检查（关节细分 ≤2°），不是连续碰撞证明；执行是单条 MovL，控制器实际插补轨迹与预演采样不会完全一致。
- 显示模型几何与测球 TCP 未做实物验证；测球 TCP 使用控制器中已配置的工具偏移，需先在 DobotStudio 完成标定。
- 碰撞检查需要本地安装厂家显示模型 `software/inspection_gui/assets/local_dobot_cr5.npz`（不随 Git 分发，缺失时相关测试自动跳过）。
- 软件停止不是安全认证联锁，实体急停必须保持可用。
