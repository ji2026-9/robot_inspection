# 坐标到点 · 安全墙预演与实际执行（2026-10-16）

入口：主界面“辅助工具 → 坐标到点”，或“实机控制 → 输入目标坐标 · 带安全墙预演”。

## 流程

1. 输入目标位姿（测量臂底座 B / 用户坐标系 0，XYZ 单位 mm、姿态单位度），可先“读取当前位置作为目标初值”。
2. 填写并确认覆盖全部工具与测针的包络半径，选择是否保持当前工具姿态。
3. 点击“生成姿态路径并检查安全墙”：后台求解整段逆解，并用显示模型逐帧检查全部连杆与工具包络是否进入玻璃安全墙禁区。
4. 用滑杆或“播放预演”逐帧查看路径与机械臂位姿，三维视图同时显示安全墙；“查看碰墙姿态”可定位第一次碰墙的姿态。
5. 预演通过后点击“实机执行”，经实机控制通道发送一条慢速目标移动。

## 窗口内自带实机授权

不需要再去“实机控制”窗口走一遍。坐标到点窗口下方有“本轮实机授权”：

- “连接实机控制”：只检查 TCP 控制模式，不使能、不运动；若实机控制窗口已连接则直接复用。
- 勾选“本次工具与现场已核对”，填写工具总重量，再点“启用本轮控制”。本轮授权 10 分钟有效；改变确认或重量会撤销授权。
- 授权有效且预演达标时，“实机执行”才可点击。关闭本窗口会撤销由本窗口启用的授权，不会留下未锁定的会话。

## 提前报错的条件

任一条不满足即拒绝执行，且不发送任何运动指令：

- 安全墙方向未确认，或工具包络半径未确认 / ≤0；
- 逆解不完整（目标不可达，或相邻采样关节跳变超过 12°）；
- 采样路径进入安全墙禁区；
- 采样最小间隙低于执行门槛 15 mm；
- 反馈不新鲜（>200 ms）、机械臂未静止、有报警、测针已触发，或坐标 / 工具配置、连接代次发生变化。

## 执行时的保护

- 目标移动速度 1–10 mm/s（默认 5 mm/s），单次一条 MovL，不排队。
- 必须在本窗口（或“实机控制”窗口）勾选现场确认、填写负载并“启用本轮控制”后才可执行。
- 运动中持续监测：偏离目标直线走廊（横向 >0.2 mm 或姿态 >0.5°）、测针 DI_1 触发、反馈中断、超时或人工停止都会请求停止并锁定。
- 执行前重新核对起点、工具偏移、安全墙指纹与连接代次，任一项变化都要求重新预演。

## 边界

- 碰撞检查是**采样**检查（关节细分 ≤2°），不是连续碰撞证明；执行是单条 MovL，控制器实际插补轨迹与预演采样不会完全一致。
- 显示模型几何与测球 TCP 未做实物验证；测球 TCP 使用控制器中已配置的工具偏移，需先在 DobotStudio 完成标定。
- 实物碰撞检查需要本地安装厂家显示模型 `software/inspection_gui/assets/local_dobot_cr5.npz`（不随 Git 分发，缺失时相关测试自动跳过）。
- 软件停止不是安全认证联锁，实体急停必须保持可用。
