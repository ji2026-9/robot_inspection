# 测头臂工作区

主界面点击 **位置记录与手动任务**；原三维预览顶部也有 **测头臂工作区** 入口。两处打开同一个窗口，共用测头臂的只读连接。

## 当前位置记录

连接后可查看实时 TCP 和关节位置。输入名称并点击保存，即可保存当前 TCP、六个关节角、用户/工具编号、控制器工具偏移、采样时间和设备状态。过期或断线反馈不能保存。

记录支持重命名、归档/恢复、JSON 导入导出；重命名不会修改原始坐标。正式位置库位于 `E:\robot_project\inspection_app\data\probe_workspace\positions.json`。本次验证记录保存在测试目录，不写入正式位置库。

## 手动任务预览

使用当前姿态或已保存位置作为起点，输入目标 X/Y/Z/Rx/Ry/Rz，也可以选中位置记录作为目标。当前只支持用户坐标系 0。生成后可播放、拖动进度或导出任务。

接近/退回候选点按目标工具的 +Z 方向和所填间距生成。请在三维中核对方向是否符合测头装配方式。位置做直线插值，姿态按最短旋转插值；没有计算逆解、碰撞或实际关节运动。预览中的机器人骨架保留起点关节姿态，运动标记表示候选 TCP 路径。导入的纯坐标任务没有关节数据时只显示路径。

手动任务始终标记为不可用于硬件执行。软件没有新增运动、使能或模式切换操作。

## 姿态核对

默认使用控制器实时 TCP 和工具偏移反推法兰，比较三维模型法兰的位置与坐标轴，并叠加显示。也可单独点击只读正解查询，使用控制器的 PositiveKin；不响应时会明确标注并退回反馈核对。

首次静态样本发现约 **4.5 mm** 法兰位置差，坐标轴角差约 **179.9°**。随后核实本机厂家模型代码，并补上遗漏的末端轴定义转换；当前坐标轴角差约 **1.08°**，位置差仍约 **4.47 mm**。剩余偏差仍需核对，不代表三维模型已经标定正确。当前控制器未响应正解查询，因此没有取得独立正解验证。

工具 1 配置中已有偏移，但配置值不能代替实物测球 TCP 标定。视觉相机和视觉臂缺席期间，可以积累位置记录、核对显示、准备人工输入任务；之后仍需测球 TCP、相机/视觉臂及两臂公共坐标系的标定，才能讨论实际执行。
