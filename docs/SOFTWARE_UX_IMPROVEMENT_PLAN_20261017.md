# 软件界面与操作流程规范化方案

日期：2026-10-17。项目：robot_inspection。

## 一、本次已完成的实机控制页调整

- 结构调整为：顶部连接与关键错误、左侧参数与控制准备、中央三维预览、底部精简状态与固定停止操作。
- 控制准备不再横占整页高度；实时位姿归入左侧信息区。普通预览完成提示置于左侧，失败与关键错误仍在页面顶部显示。
- 播放条与虚拟 TCP 紧邻三维窗口；说明默认折叠到“详情”，保留一行距离、倍率、预计时间摘要。
- 三维视口自适应可用空间，限制过宽的横向比例；窗口变化时适配完整机械臂。视口几何与相机投影独立处理，不通过拉伸模型填满窗口。
- 左侧参数独立滚动，可拖动分栏，仍可放大预览；错误、详情与放大状态下保留停止按钮。
- 本次只调整布局与信息呈现，不增加运动授权，不自动连接或移动实机。

## 二、检查范围和判断

根据当前主工作台、实机控制、测头任务、安全墙、设备连接、白球分析、模型管理的页面结构，以及隔离 Qt/OpenGL 界面检查进行评估。界面验证不等于真实硬件功能验收。

主要问题是随着功能追加，任务入口、参数、调试工具和状态说明混在同一级；不同页面的状态与按钮样式也不完全统一。应先整理流程和状态，再统一样式，最后做功能扩展，避免继续堆叠页面。

## 三、建议按优先级实施

| 优先级 | 调整项 | 建议做法 | 验收方式 |
|---|---|---|---|
| P0 | 全局状态统一 | 固定显示真实连接/模拟模式、控制是否可用、运行/停止核对状态、测头状态、全局倍率及安全墙确认状态；信息来自同一反馈源 | 切换页面状态一致；失联后明确失效，不显示上次数据为实时值 |
| P0 | 操作状态统一 | 明确未连接、已连接待准备、可操作、预览中、运动中、停止核对中、异常锁定；按钮可用条件与状态一致 | 按钮禁用能看到原因；停止不依赖当前页面，关闭提示不自动续走 |
| P0 | 故障处理闭环 | 每条关键错误包含发生时间、任务/目标、原因和下一步；支持复制与历史记录；提示与原始日志对应 | 断线、无触发、保存失败等可追溯；重复故障不刷屏，不能确认停止时提示实体急停 |
| P1 | 导航和任务入口 | 组织为“工作台、测量任务、实机控制、设备与标定、记录与模型”；安全墙状态持续可见且有直接入口；实验/停止测试归入诊断区 | 高频操作不超过两层；入口跳转复用同一页面，避免重复窗口 |
| P1 | 组件与文案规范 | 统一按钮高度、主次按钮、8/16/24间距、标题层级、数字输入、单位、禁用/焦点样式；颜色同时配文字 | 同类控件行为一致；键盘 Tab 可顺序操作，Esc 请求停止；只读信息可复制 |
| P1 | 名词与数据来源 | 区分 TCP/IP 通信与工具中心点 TCP；区分自定义原点（返回位置）与机械零点；明确控制器反馈、模型预览、计算结果、模拟示例 | 每项坐标标注坐标系、工具号和单位；实验结果不显示成已标定值 |
| P1 | 多目标任务编辑 | 用可勾选的目标表，列出编号、XYZ、是否执行、状态；提供编辑、上移/下移、插入、任务保存和另存 | 修改后旧预览失效；执行只采用已确认任务快照；停止取消剩余运动 |
| P1 | 测量流程产品化 | 将圆孔测量做成独立任务：设置→预览→采点→结果；正常触发和异常触发分开，显示当前阶段、点数和退离状态 | 单点测试后验证四点/八点循环；反馈丢失或退离不释放时终止，不盲目继续 |
| P2 | 标定与配置管理 | 工具/TCP、测针有效半径、工件坐标、安全墙使用版本及确认状态；历史测量绑定当时配置 | 配置变化后旧任务须重新校验；支持备份和回滚 |
| P2 | 数据与发布管理 | 统一任务/结果/日志目录；记录软件版本、设备、时间、配置与算法版本；导出报告保留原始点 | 换电脑后可恢复项目；发布包与源码版本可核对，旧数据不被覆盖 |

P0 表示应优先解决的一致性和异常处理；P1 是日常操作体验；P2 是正式测量与交付的长期管理。此表为后续方案，除第一节外并非已经全部实现。

## 四、统一页面模板

1. 顶部：页面名称、当前模式、与该页有关的设备和连接动作。
2. 主区：左侧任务参数，中央图像/三维/结果，必要时右侧属性详情。
3. 信息反馈：关键错误固定可见，普通成功提示占用较小空间，详细日志按需展开。
4. 底部：当前阶段、进度及主要动作；实机页停止入口固定，保持最高可见优先级。
5. 空状态：说明现在缺什么以及从哪里开始；加载状态给出正在做什么，并提供可取消入口。

## 五、建议验收清单

- 小、中、大窗口下检查布局；覆盖100%、125%、150%缩放，必要时增加200%。按实际可用窗口尺寸适配，而不是仅按显示器分辨率。
- 页面允许参数区滚动，主要动作和停止不能滚出视野。普通成功提示不得使预览明显缩小，详细说明不得长期占据主画面。
- 普通文字对比度以4.5:1作为检查目标；状态不能只靠红绿区分，键盘焦点可见，字段有明确标签和单位。WCAG 用作桌面界面的可访问性检查参考。
- 覆盖模拟、只读反馈、控制已连接、运行、停止、超时、断线、配置变化等状态，检查文字和按钮一致。
- 硬件动作另行分阶段验收；软件界面规范化不能替代控制器安全配置或机械安全认证。
