# 实机控制界面

入口：主界面 **测头工作区 · 记录与实机控制** → 右上角 **实机控制 · 默认锁定**。

该界面直接连接 Dobot TCP 29999 控制接口，复用本软件 30004 实时反馈。TCP 模式已在控制器上选择且机械臂已正确配置并使能后，不需要在官方软件中点击移动。它不是官方软件全部设置功能的替代品，不自动切模式、上使能、清报警或修改负载。

## 操作

1. 在测头工作区连接只读反馈，核对真实位姿和 DI_1。
2. 打开实机控制，点击“连接 TCP 控制（不移动）”。该动作只查询 RobotMode，不发送运动。
3. 实际核对工具、负载重心、现场空间和急停，逐项确认，填入已核对的工具总重量。此数值只作现场确认记录，不会配置控制器负载。
4. 确认后解锁60秒。每次解锁单次最多1 mm，累计最多5 mm，距解锁起点最多5 mm。默认步长0.1 mm、目标速度1 mm/s，最大目标速度5 mm/s。
5. 点击 X/Y/Z 的方向按钮，查看保持原姿态的目标预览（10秒有效）；按住执行按钮才发送一条真实 MovL 指令。不能排队连续执行路径。
6. 松开、点击红色停止按钮、测头 DI_1 触发、反馈超过200 ms未更新、配置变化、授权到期、窗口失焦/关闭，会请求软件停止并重新锁定。停止不自动恢复运动。

速度是指令目标值，不是实测制动性能。停止按钮是软件停止，不是安全急停。PC故障、网络、控制器及制动存在延迟；软件距离限制不能保证过冲不越界。人员身体和手持物不得用于阻挡运动测针。此版本尚未进行实机运动验证，静止触发通信成功不等于运动接触可安全停止。
