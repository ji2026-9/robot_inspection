# 实机控制：连续点动与定距调整

入口：主窗口顶部“实机控制”工作页。设备连接、测头任务、三维预览等均在同一主窗口切换；更新后重开软件生效。

## 连续点动（默认）

1. 在实机控制页核对 IP，点右上角“连接控制”。没有反馈时先建立只读反馈，稳定后查询控制状态；连接本身不移动。已有反馈的 IP 必须与输入 IP 一致。
2. 核对工具、负载重心、工具坐标与现场条件，填入核对过的工具总重量，勾选本次确认，点“启用本轮控制”。重量只作记录，不修改控制器负载。
3. 直接按住 X+/X−、Y+/Y−、Z+/Z−：长按持续点动，松开请求停止。不需要先生成目标或再点执行。
4. 松手后检查停止应答和新反馈；正常稳定后方向按钮自动恢复可用，再次按下即可点动。无需点“继续控制”、重新勾选或重新连接。停止核对期间的按键不缓存，请松手后重新按下。

点动采用厂家 V4 `MoveJog`，每次按住只发送一次启动指令，松手发送停止请求。短按的位移取决于按住时间、加减速和通信延迟，不是精确步长；极短按键可能在指令发送前被取消。

点动倍率预设1%、2%、3%、5%、8%、10%，也可输入1–10的整数，默认1%。实际点动速度由“控制器点动设置 × 全局速度倍率”决定，不能把1%理解为1 mm/s。程序在每次点动前发送 `SpeedFactor` 设置所选全局倍率，停止或退出后不自动恢复更高倍率。该参数有别于负载、重心和标定配置。

本次人工确认有效10分钟，可多次点动，不再有原来的累计5 mm限制。每次按住可设置0.01–100 mm行程上限，默认100 mm；到达所设上限正常请求停止，停止核对后可再次按下。每次按住超过30秒或其他保护边界则停止并锁定。位置上限是电脑端反馈检查，不能保证制动无过冲。

## 定距移动

切换为“定距移动 · 精细调整”。距离支持0.01–100 mm，常用预设0.01、0.05、0.1、0.5、1、2、5、10、20、50、100 mm，也可直接输入，例如7.25 mm。目标速度支持1–20 mm/s整数，预设1、2、3、5、10、15、20。点方向核对目标，再按住执行。松手会请求停止；正常停止反馈核对完成后，可直接选择下一次目标。本次确认期间可反复调整，单次最多100 mm。修改参数后旧目标作废，需要重新选方向核对目标。两种模式分别记住本次窗口内设置的距离和速度。

## 手动停止、保护锁定与结束

- 红色“停止移动”：暂停并保留连接；反馈稳定后点“继续控制”，再进行新操作。不会恢复旧目标。
- 松开正在移动的方向或执行按钮：正常停止后自动恢复输入，只接受新的按下动作。
- 窗口失焦或隐藏：请求停止，需手动继续；关闭窗口或断开结束会话。
- “结束本轮并锁定”：撤销本次确认；停止核对完成后解除锁定，再重新启用。
- 测头DI_1触发、报警、反馈中断、配置变化、超出范围或超时：撤销自动恢复资格，处理原因后重新确认。不能通过松手覆盖异常锁定。

只有一个方向可以运行；移动或停止核对期间不排队其他方向。界面按住信号中断、通信异常或控制器拒绝都会停止/锁定，不自动重试运动。

## 验证与边界

138项自动测试、9项统一工作台流程检查通过，包含真实控件的三次按住/松开模拟、原生点动协议、本地socketpair、松手时序、无缓存/重放、异常锁定和100 mm/30秒检查。均使用假反馈和假控制通道；没有连接实机控制端口，没有发送实机运动指令。实际设备点动兼容性、速度和停止距离仍待现场验证。

软件停止存在电脑、网络和制动延迟，不能替代实体急停或控制器硬件保护。控制器须事先处于TCP模式、已使能且工具与负载配置正确；程序不会自动使能、清报警或切换模式。

协议依据：[厂家 V4 Python 接口中的 MoveJog 和 SpeedFactor](https://github.com/Dobot-Arm/TCP-IP-Python-V4/blob/main/dobot_api.py)。


## 停止优先修复（2026-10-16）

执行按钮下方增加红色“停止运动（Esc）”，按下即请求停止，不必等鼠标松开；底部停止按钮保留。在控制页按 Esc 同样请求停止。

停止事件在等待线程锁之前置位，唤醒控制线程，撤销运动授权和待发目标。控制线程先处理停止再取移动任务，不重放被取消的目标。测头 DI_1=1 在每帧反馈处理中锁存停止，松开测头不会自动恢复本轮。

修复定距移动停止失败：旧版本先发送 MoveJog()，控制器返回 -1 后异常中断，未继续发送 Stop()。新版本定距模式直接发送 Stop()；原生点动分别尝试停止运动队列和取消点动，任一失败不跳过另一请求。失败仍锁定并明确提示无法确认停止，不以应答代替真实停止反馈。

日志增加停止请求原因、DI位值、请求时间和失败指令清单。已有旧日志没有触发时刻记录，不能据此判定那一次是否收到 DI 信号。

138项离线自动测试和9项工作台检查通过，新增覆盖真实协议解析中的拒绝应答、短DI脉冲、待发移动取消、停止按钮按下及Esc。没有发送实机运动指令。最高优先级是本程序的处理顺序，不是硬件急停：正在进行的通信应答、反馈采样、网络与制动仍有延迟；未验证实机停止距离。升级后先在静止状态核对DI触发及停止应答，不能直接拿碰撞测试验证。

官方协议：[Stop() 停止已下发运动队列](https://github.com/Dobot-Arm/TCP-IP-Python-V4/blob/main/dobot_api.py)。
