# 多目标控制与安全墙预警

实机控制 → 指定坐标 / 多目标路线。输入 XYZ，点击“添加目标”，重复添加最多 20 个目标。按列表顺序自动生成保持当前姿态的直线分段路径；可删除、上移或清空目标。列表为空时，仍可直接预览单个输入坐标。

点击“规划并预览路径”，检查完整路线，确认后点击“确认预览并执行”。按实际全局倍率估算播放时间（未计加减速）；倍率为零时保持静止。拖动分栏调整宽度，或点击“放大预览”，底部停止按钮始终可见。

整条路线先经过安全墙检查，每段发送前再次核验。每次只发送一条运动指令，收到后续新鲜反馈、确认到点静止后才发送下一段。停止、测头触发、反馈中断、配置变化、失焦、会话到期均取消剩余目标，恢复后不自动续走。软件停止有通信延迟，不能代替实体急停。

真实运动发现安全墙侵入时先设置最高优先级停止请求，再异步弹窗；路径预览发现进入墙面或停止预留区时拒绝执行并弹窗。重复提示合并，关闭弹窗不恢复运动。主界面保留全局墙状态与安全墙页签，删除右上角重复设置按钮。

路径规划只针对输入目标做连续逆解、分段直线及安全墙检查，不自动绕过未建模障碍，也不代表自碰撞或连续碰撞认证。真实墙的位置和工具包络仍须现场确认，示例值不会写成真实位置。

验证：222 项离线回归通过（2 项跳过）；Windows OpenGL 界面验收通过，验证多目标、预览放大、停止入口及弹窗。本次未连接真实控制通道、未移动实机。
