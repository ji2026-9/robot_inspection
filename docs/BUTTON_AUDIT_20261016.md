# 近期新增按钮核对与修复（2026-10-16）

## 已复现并修复

| 问题 | 触发方式 | 修复结果 |
| --- | --- | --- |
| Esc 隐藏窗口但跳过清理 | 测头工作区、白球分析、独立停止测试或三维窗口按 Esc | 统一执行关闭清理：停止定时器、停止采集、取消后台计算，独立监控按原规则请求结束 |
| 结束采集漏掉最后一点 | 新触发已收到，但 200 ms 界面轮询未执行就点结束 | 结束前先刷新并纳入已收到的记录，再保存和刷新表格 |
| 两个窗口争用 TCP 控制端口 | 独立停止测试窗口已打开，再连接实机控制后返回测试窗口 | 禁用冲突按钮并解释原因；执行入口再次拦截 |
| 正解查询争用 TCP 控制端口 | 已连接实机控制时点控制器只读正解 | 明确禁用并提示先断开控制；普通反馈姿态核对仍可使用 |
| 旧目标仍显示可执行 | 方向预览已超过 10 秒 | 自动撤销界面预览并禁用执行，提示重新选方向 |
| 错误提示容易被遮住 | 控制操作失败，提示在滚动区末端 | 将错误信息固定在窗口状态区，无需滚动查看 |
| 未选择采点仍可点排除 | 结束采集后没有选择表格行 | 无选中行时禁用排除按钮，并增加提示 |

## 已核对流程

位置记录、重命名、作为预览起点、归档与恢复、导出位置库；白球采集结束、重复性分析、排除与恢复、导出与重新打开；模拟视觉示例载入、实际离线逆解计算、播放、回到起点、聚焦与导出；窗口关闭、控制互斥、目标有效期和保护复位流程。

109 项自动测试通过（包含新增 12 条按钮流程回归），另外 12 项实机控制界面检查通过。测试使用独立临时数据、假反馈和假控制通道，禁止真实网络连接；未改动实机记录，未发送实机运动指令。按钮流程测试使用替代三维画布，离线关节计算仍使用实际算法；本次未验证真实显卡三维绘制性能。

## 仍然有条件或尚未开放的按钮

- 主界面“发送测量任务”：自动测量流程尚未具备完整标定及执行验证，继续禁用；可通过“测量就绪检查”查看缺项。
- 实机控制的解锁、执行、复位：须分别满足反馈、现场确认、目标预览、停止后核对等条件。被保护条件禁用时不是按钮失灵。
- 独立停止测试与控制器正解查询：不能和实机 TCP 控制同时占用控制端口。
- 分析按钮：需要先结束本组并取得足够有效采点；重复性至少 5 点，球面拟合至少 9 个分布位置。
