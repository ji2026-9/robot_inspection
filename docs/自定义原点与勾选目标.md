# 自定义原点与勾选目标

位置：实机控制 → 指定坐标 / 多目标路线。向下滚动左侧面板可见原点区。

## 勾选执行目标

输入 XYZ 后添加目标。列表每行勾选表示本次执行，取消勾选则跳过；顺序按照列表，可用“上移”调整。支持全选、全不选。摘要显示本次选择及执行顺序，例如“1 → 3 → 5”。

点击“规划并预览路径”只规划已勾选目标；确认完整预览后再点击“确认预览并执行”。列表非空但全部未勾选时会拒绝规划，不会退回执行输入坐标。修改勾选、增删或顺序会取消旧预览。列表为空时保留单坐标预览功能。

## 设置和返回原点

“当前位置设为原点”：从新鲜静止反馈保存当前 TCP XYZ。“输入坐标设为原点”：保存上方输入的 XYZ。两种方式均只保存位置，不发送运动、不改写控制器坐标系。

原点以用户坐标0（B基座）记录，自动保存在 data/probe_workspace/manual_origin.json 对应工作区。重开软件保留；机械臂地址或工具/用户配置变化时拒绝复用，须核对后重新设置。

“回到原点 · 先预览”：单独规划当前位置到原点的路径，保持当前工具姿态；本次不执行目标列表。检查预览，再点击底部“确认预览并执行”。若已在原点附近（小于0.01mm），提示无需移动。保留安全墙、测头、停止按钮与所有现有检查。不会自动绕过未知障碍。

验证：230项离线回归通过（2项跳过），Windows OpenGL 界面验收通过；没有连接真实控制通道、没有移动实机。既有安全墙配置及真实原点未被写入示例值。
