# 数值增减按钮与完整项目同步

2026-10-16，v1.4-workbench。

本次将实机控制、三维预览、测头任务、相机参数、设备端口的数值输入统一为清楚的“−／＋”按钮。按下立即调整，长按450ms后每100ms重复调整，松手结束；可以继续直接输入。到达上下限、参数只读或控件被禁用时，按钮变灰。

距离框和速度框保留常用值下拉选项，并增加真正的增减操作，避免把下拉箭头误认为增减按钮。数值输入不会发送运动指令。

| 参数 | 每次调整 |
| --- | --- |
| 控制距离/连续点动行程上限 | 0.1 mm，可直接输入0.01 mm等值 |
| 定距目标速度 | 1 mm/s |
| 连续点动倍率 | 1% |
| 工具总重量（人工声明） | 0.1 kg，不写控制器负载配置 |
| 预览目标XYZ/姿态角 | 0.1 mm / 0.1° |
| 三维尺寸 | 0.1 mm |
| 预览播放倍率 | 0.25倍 |
| 相机期望曝光/增益 | 100 μs / 0.1 dB，实际范围仍由驱动限制 |
| 可编辑设备端口 | 1；测量机械臂反馈端口固定30004，保持只读 |

156项自动测试与9项工作台流程检查通过。新增按钮验证覆盖按下立即生效、松手不多加一次、长按重复、直接输入后调整、上下限、只读/禁用、参数模式切换及各功能页；不连接实机、不写入相机、不发送运动。

完整发布还包含此前未同步的统一工作台、控制暂停/继续、原生长按点动、停止优先级修复、页面性能优化和新版模型管理。性能验证与软件停止边界分别见 PERFORMANCE_20261016.md、manual_control_safety.md。
