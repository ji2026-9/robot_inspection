# v1.4 工作台安全墙扩展

入口：主窗口顶部“安全墙”；“测头任务”内的安全墙按钮打开同一页。

左侧设置，右侧三维视图。读取已有 data/probe_workspace/safety_wall.json，不擅自更改墙距。当前本机保存的是 +Y、300 mm；操作者口述约330 mm，需现场核对。宽高仅为绘图范围，碰撞检查按无限禁入半空间计算，避免从绘图边缘漏过。

可以保存、显示草稿，检查静止反馈快照，以及已完整求出关节逆解的预览路径。碰撞显示模型部位标红，测试快照单独标识，可清除恢复原预览。检查按底座及 J1–J6 显示网格进行；工具与测针仅在操作者确认包络半径后纳入检查，未确认时显示未检查工具。

路径为最大单轴2°的关节插值采样检查，不是连续碰撞检测，不验证控制器插补轨迹，也不检查自碰撞。显示网格及测针几何未完成实物校验。所有报告 hardware_executable=false；本扩展不自动启用实机控制，不接入运动指令拦截，不能作为实际防撞保护。

日志保存于 data/probe_workspace/wall_tests/。修改墙或工具包络参数使旧测试结果失效。

在原 v1.4 main 基础上只新增3个模块，并修改工作台入口、测头页入口和三维显示接口；未替换主线工作台、实时反馈或运动控制模块。添加3个测试文件；整合测试170项，169通过、1项缺少测试指定厂商资源而跳过。窗口测试使用隔离控件，实机运动和真实OpenGL画面尚未现场验收。
