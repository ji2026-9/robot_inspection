# Gemini 335Le 接入

基于 GitHub 主线 3003709 的 scripts/app_addons/orbbec_camera.py 整合。
保留现有双画面、拍摄留样与实验记录入口；没有部署朋友的独立预览窗口和目录。

## 使用

1. 安装厂家 OrbbecSDK v2；支持自动查找 Program Files 下的 2.9.3/bin，也支持 ORBBEC_SDK_BIN 指定目录。
2. 电脑网卡和相机配置在可通信的网络内，设备 IP 不重复。本软件不会修改网卡、相机或机器人 IP。
3. 在设备连接的工业相机页填写当前 IP、端口（通常 8090）、可选的准确序列号，保存配置。
4. 点击主界面开始采集。连接和取流在后台进行，拍摄仍写入 data/camera_captures，实验记录可浏览所有留样。

## 本次修正

- 按 IP 使用 ob_create_net_device；填写序列号时进行真实序列号核对，找不到不回退到第一台设备。
- 未填写 IP 时只允许准确序列号选择，或唯一设备枚举。
- DLL 目录句柄持续保留，按本机 SDK 头文件核对 C 接口与图像格式。
- 每次取帧最多等待 500 ms；3 秒无新图像时连接失效，预览缓存超过 2 秒不可拍摄，线程结束清空缓存。
- 采集中禁止直接断开，先停止取流；设备状态每秒刷新，不反复写相同状态日志。
- 留样增加真实型号、序列号、设备标识、流配置；未实现的实际曝光/增益仍保持未知。
- 所有分割轮廓均尝试原图孔口边缘精修，仅使用通过原有支持率、覆盖率和重采样稳定性检查的修正结果。

## 验证与限制

本机真实 SDK DLL 加载和接口绑定通过。离线测试验证 IP/序列号选择、后台连接、RGB 转换、断流状态和旧帧拒绝。
五张历史实拍图检测回归为 20 个孔 / 20 个圆心，测试结果单独保存于 updates/orbbec_integration_check，不加入正式实验记录。
逐孔精修测试18/20通过，2个保留原拟合；没有测量真值，因此未宣称毫米精度改善。
电脑当前有线网卡为 APIPA 地址，尚未进行这套集成后的实机相机取图验证。
目前接入彩色流，不包含深度对齐、三维孔心、手眼标定或机械臂运动。
SDK 接口参考：https://orbbec.github.io/docs/OrbbecSDKv2/_context_8h.html
