# 整合界面

桌面的“箱体孔检测”快捷方式启动本界面。入口为 `app.py`，使用本机 `.venv` 环境。

## 操作

1. 点击“选择一组照片”，可一次选多张本机照片。
2. 点击“开始检测”，逐张处理；通过上一张、下一张或下拉列表查看结果。
3. “实验记录”显示每组结果，带表格线；下一组追加保存，可导出 CSV 至 Excel/WPS。
4. “添加训练数据 / 自动更新”打开原有 Labelme 和训练管理流程。
5. “训练验证结果”打开最新一次训练前后对照及正式模型选择说明。

## 保留的检测与数据

- `detect_core.py` 负责全部识别、part 约束、旋转恢复、反光处理和圆心拟合。
- 正式模型由 `active_models.json` 指定，分别加载自己的 bore 与 part 权重。
- 原有数据库、标注、实验记录及模型文件保留原路径。
- GUI 不重新拟合圆，也不采用朋友界面的旧模型路径。
- `vision.py` 仅转换输出字段，失败或需要复核的圆心不作为可靠测量目标。
- 图像孔号按当前图像位置排列，并非跨照片的固定物理孔号。

## 设备与坐标边界

设备参数只在本次运行中使用。相机已有 Orbbec 驱动，机械臂 B 已有 DOBOT V4 的 30004 接收反馈接口；连接和配置分别显示。

从主界面的“三维定位与路径预览”打开三维窗口，可切换“实时机械臂 B（只读）”和“离线路径预览”。当前已验证设备为 CR5A，地址 192.168.5.1。首次打开会尝试此地址的只读反馈，其他机器请按实际设备 IP 修改。读取实际六轴关节角、TCP 位姿、用户/工具索引、使能/运行/报警状态；中断后清除实时显示并提供重新连接入口。没有使能或运动命令。

外观模型使用实测关节角驱动，但显示关节链并未经过 CR5A 实机几何校验。真实 TCP 数值来自控制器；用户坐标为 0 时显示 TCP 坐标轴，其他用户坐标仅显示数值。基座摆放和工件均为模拟值。TCP 彩色坐标轴和外观法兰位置可能不同，不可据此判断实际空间位置或碰撞。

孔圆心仍为图像像素坐标。孔到三维和机械臂的坐标转换、手眼标定、真实测针 TCP 及碰撞验证尚未完成，发送测量任务按钮保持禁用。

2026-10-13 更新：后台加载三维资源、原生索引数组编译显卡缓存、回收旧几何缓存；单线程生成路径并取消过期计算；修复无效参数/空选择保留旧路径和低于一倍速度播放；主界面可拖动分栏、参数滚动、小屏布局、图像重绘合并和设备连接状态同步。

## 界面来源与改动

参考用户提供的 `robot_inspection_gui_v1.zip` 的布局和图像显示方法。
原包源码保存在 `friend_gui_source`。新界面代码位于 `inspection_gui`。
移除了朋友模型对照、检测方案选择、合并标注复核及模拟执行入口。
