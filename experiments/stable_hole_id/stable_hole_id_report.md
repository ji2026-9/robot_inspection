## 三、最终报告（对应要求的 10 个问题）

**1. 当前 PCA 排序是否稳定？**
**不稳定。** PCA 只给出「轴」，不给出「方向」。当前实现为了可复现，把主轴强制指向图像 +x；这**不是物理方向**，只是一个图像坐标系约定。

**2. 180° 旋转是否会导致 H01/H04 对调？**
**会，且已实测。** 4 张图旋转 180° 后，测试1/2/4 的 **4/4 个孔全部对调**（H01↔H04、H02↔H03），id 一致率为 **0%**。

**3. 当前四张照片能否找到稳定物理方向？**
**不能。** 证据三条：
① 孔组本身**没有 180° 破缺特征**——测试4 证明四孔物理等距（差 0.9%）等大（差 2.7%）；
② 测试1/2 的间距/孔径梯度是**透视效应**（相机视角造成），不是物体内在特征，且在测试4 中完全消失；
③ 唯一可能提供内在非对称的**箱体外轮廓无法可靠分割**（Otsu 抓到背景；GrabCut 4 张里 2 张失败）。

**4. 哪种视觉特征可以作为方向参考？**
在**当前这 4 张图**中，**没有任何一种可被可靠、自动地提取**。可选（但需额外条件）的备选排序：
- ① **外部参考轴**（来自夹具/工作台/标定坐标系）—— 本模块已实现（M1），提供即 `stable`；
- ② **箱体外轮廓非对称**（需先有可靠的箱体分割）—— 本模块已实现（M2）但**带严格校验，当前 4 张图未通过**；
- ③ 工件上的**固定参考标记**（打点/贴标/加工基准）—— 当前数据中不存在。

**5. 如果可以，稳定编号规则是什么？**
模块 `stable_hole_id.py` 已内置方法链：
```
M1 external_reference_axis : 给定图像坐标系参考方向 → status=stable
M2 silhouette_asymmetry    : GrabCut 外轮廓 + 严格校验（含 n-1 个孔中心、面积占比 0.02~0.45）→ 通过才 stable
M3 none                    : 都不成立 → status=uncertain（仍输出排序，但声明可能对调）
```
验证：`--reference-axis 0.15,-0.99` 时模块正确输出 `status=stable, method=external_reference_axis`（见 `results\demo_with_reference.json`），说明扩展路径已就绪。

**6. 如果不可以，缺少什么信息？**
按优先级：
1. **一个稳定的对象内在参考**：箱体上的固定标记（打点/贴标），或工件自身被确认的非对称结构；
2. **可靠的箱体分割**：需要一个能稳定分出工件外轮廓的方法（现有 4 张图的背景太杂，经典方法不可用）；
3. **相机/工作台坐标系**：若机器人工作站固定，可用工作台坐标系方向作为 M1 参考轴；
4. **带已知物理朝向的参考照片**：至少一张明确标注"这一端是 H01 端"的照片，用于标定参考轴。

**7. 当前方案能否用于机器人"测量 H03"？**
**不能直接用于物理语义的 H03。** 当前编号只能在**同一相机、同一摆放约定**下保持相对一致；一旦工件旋转 180°（或相机换到对面），"H03"会指向另一个物理孔，机器人会去测错孔。
**可用于**：相机固定 + 工件以固定方向上料的场景（此时建议把该固定方向显式作为 M1 参考轴传入，状态即可变为 `stable`）。

**8. orientation_status 在四张图片上分别是什么？**
**四张全部为 `uncertain`**（`orientation_method = "none"`），因为 M2 未通过校验、且没有提供 M1。

**9. 是否需要额外拍照/标记？**
**需要**，建议按成本从低到高：
1. **一个固定参考标记**（箱体上一个打点/贴标/加工基准边），拍进每张图 → 可稳定消歧，成本最低；
2. **固定上料方向**（工装定位），并把该方向作为 M1 参考轴传入 → 无需改图，但依赖工装；
3. **补拍带明显非对称端的照片**（如箱体一端的凸台/斜面完整入镜）并训练/标注箱体轮廓 → 可让 M2 生效。

**10. 本阶段是否修改了现有模型和数据？**
**没有。** 未训练（未调用 `model.train()`）、未改 `best.pt`、未改数据集/ZIP/测试图/runs/已有 experiments；`predict_holes.py` 只读未改。新增内容全部位于 `experiments\stable_hole_id\`。

## 六、下一步建议（按性价比排序）

1. **最低成本**：在箱体上加一个固定参考标记（或利用现有明显非对称端），拍进所有照片，然后用 `--reference-axis` 或扩展 M2 实现真正的 `stable`；
2. **工程化**：若机器人工作站有固定工装，直接用工作台坐标系方向作为 M1 参考轴；
3. **数据侧**：若要自动消歧，需要能稳定分割箱体轮廓——建议专门采集/标注少量箱体外轮廓数据（这属于新任务，不在本阶段范围内）。
