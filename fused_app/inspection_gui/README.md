# 整合界面

桌面的“箱体孔检测”快捷方式启动本界面。入口为 `app.py`，使用本机 `.venv` 环境。

## 操作

1. 点击“选择一组照片”，可一次选多张本机照片。
2. 点击“开始检测”，逐张处理；通过上一张、下一张或下拉列表查看结果。
3. “实验记录”显示每组结果，带表格线；下一组追加保存，可导出 CSV 至 Excel/WPS。
4. “添加训练数据 / 自动更新”打开原有 Labelme 和训练管理流程。
5. “训练验证结果”打开最新一次训练前后对照及正式模型选择说明。

## 保留的检测与数据

- `detect_core.py` 负责全部识别、part 约束、旋转恢复、反光处理和圆心拟合。
- 正式模型由 `active_models.json` 指定，分别加载自己的 bore 与 part 权重。
- 原有数据库、标注、实验记录及模型文件保留原路径。
- GUI 不重新拟合圆，也不采用朋友界面的旧模型路径。
- `vision.py` 仅转换输出字段，失败或需要复核的圆心不作为可靠测量目标。
- 图像孔号按当前图像位置排列，并非跨照片的固定物理孔号。

## 设备与坐标边界

设备窗口保存工业相机、拍照机械臂 A、测量机械臂 B 的连接配置。
目前未接入真实厂商 SDK；配置保存不代表设备已连接。
圆心为图像像素坐标，三维坐标、手眼标定和机械臂坐标转换尚未实现。
因此发送测量任务按钮保持禁用，没有真实机械臂运动。

## 界面来源与改动

参考用户提供的 `robot_inspection_gui_v1.zip` 的布局和图像显示方法。
原包源码保存在 `friend_gui_source`。新界面代码位于 `inspection_gui`。
移除了朋友模型对照、检测方案选择、合并标注复核及模拟执行入口。

共生成 4 行实验记录；正式模型配置、已有实验记录、已有最近一组结果的校验值未变。
